# 삼국기 (三國記)

한국 삼국시대(고구려·백제·신라)를 배경으로 한 턴제 전략 시뮬레이션 게임입니다.
KOEI 사의 삼국지 시리즈를 벤치마킹하여 **내정 + 외교 + 전쟁**을 모두 포함한 올라운드 게임으로 만들었습니다.

순수 **HTML + CSS + Vanilla JavaScript**로 구현되어 빌드 도구나 외부 의존성이 전혀 없습니다.
(npm / node_modules / 외부 CDN / 외부 폰트 없이 오프라인에서 완전히 동작합니다.)

---

## 실행 방법

브라우저의 보안 정책상 `file://` 로 직접 열면 일부 동작이 제한될 수 있으므로,
간단한 로컬 정적 서버로 서빙하는 것을 권장합니다. (Python 3만 있으면 됩니다.)

```bash
cd /projects/sandbox
python3 -m http.server 8000
```

그 다음 브라우저에서 접속합니다:

```
http://localhost:8000
```

> 참고: 별도 서버 없이 `index.html` 파일을 브라우저로 직접 열어도 대부분 동작합니다
> (모든 스크립트가 일반 `<script>` 태그로 로드되며 ES Module을 쓰지 않기 때문입니다).
> 다만 안정적인 실행을 위해 위의 로컬 서버 방식을 권장합니다.

---

## 게임 방법

1. **타이틀 화면** — "새 게임 시작"을 누릅니다.
2. **군주 선택** — 고구려 / 백제 / 신라 중 하나의 국가로 시작합니다.
   각 국가는 고유의 색상 테마, 난이도, 특성, 초기 병력을 가집니다.
3. **메인 게임 화면**
   - 한반도 지도에서 성(도시)을 클릭해 정보를 확인합니다.
   - 아군 성: **내정**(개발) / **출병**(공격) 가능
   - 적/중립 성: **공격** 가능 (가장 병력이 많은 아군 성에서 자동 출병)
   - 상단 HUD: 금, 세수, 총병력, 영지 수, 연도/턴
   - 좌측 메뉴: 무장 열전 / 외교 / 연표
   - "턴 종료"를 누르면 세수 수입, 병력 회복, AI 행동, 역사 이벤트가 처리됩니다.
4. **내정** — 농업 개발 / 상업 진흥 / 성벽 보강 / 병사 모집 (금 소모)
5. **외교** — 사신 파견, 조공, 동맹 제안(관계 30 이상), 선전포고
6. **전투** — 턴제 전술 전투. 총공격 / 방어 / 필살전법 / 퇴각을 선택하며,
   무장 능력치(통솔·무력) + 병력 수 + 지형(치안) 보정으로 피해를 계산합니다.
   적 수비군을 전멸시키면 성을 함락합니다.
7. **무장 열전** — 아군 무장의 능력치(통솔/무력/지력/정치)와 배치를 확인합니다. 적국 무장은 첩보(숨김) 상태입니다.

### 승리 / 패배 조건
- **승리**: 중립을 제외한 모든 성을 차지(천하통일) 하거나, 200턴 시점에 최다 성 보유
- **패배**: 보유한 성이 모두 함락되거나, 200턴 시점에 최다 성 보유국이 아님

## 파일 구조

```
/projects/sandbox
├── index.html            # 진입점 (모든 스크립트 로드)
├── styles/
│   └── main.css          # 전체 스타일 (수묵/전통 테마)
├── data/                 # 게임 데이터
│   ├── kingdoms.js       # 국가(고구려/백제/신라) 메타데이터
│   ├── characters.js     # 무장 능력치 데이터
│   ├── cities.js         # 도시(성) 초기 데이터 + 지도 좌표
│   └── events.js         # 역사 이벤트 정의
├── js/                   # 게임 로직 및 UI
│   ├── store.js          # 게임 상태 저장소 + 핵심 로직 + AI
│   ├── ui.js             # DOM/SVG 렌더 헬퍼 (엠블럼, 아바타, 능력치 막대)
│   ├── map.js            # 한반도 SVG 지도 렌더
│   ├── screens.js        # 타이틀 / 군주 선택 화면
│   ├── overlays.js       # 내정 / 외교 / 무장 / 전투 오버레이
│   ├── game.js           # 메인 게임 화면 + HUD + 이벤트 팝업
│   └── app.js            # 앱 진입점 (상태 구독 → 렌더)
└── README.md
```

## 기술 메모
- 프레임워크·번들러 없이 동작하는 순수 웹 기술 구현입니다.
- 전역 네임스페이스 `window.SAMGUK` 아래에 데이터/스토어/UI 모듈을 등록합니다.
- 상태는 단일 상태 객체 + 구독(subscribe)/전체 재렌더 방식으로 관리합니다 (React/Zustand 개념을 Vanilla JS로 치환).
- 지도, 국가 엠블럼, 전장 그리드는 모두 인라인 SVG로 그립니다.
- 폰트는 시스템에 설치된 한글 폰트 스택을 사용합니다 (외부 폰트 로딩 없음).
