# 삼국기 (三國記)

한국 삼국시대(고구려·백제·신라)를 중심으로 당·왜까지 아우른 **5세력 턴제 전략 시뮬레이션** 게임입니다.
KOEI 사의 삼국지 시리즈, 그리고 사극 사장(社長) 히트작 **『Legend of Heroes: Three Kingdoms』**(영걸전 계열의 하이 프리덤 삼국 샌드박스)을 레퍼런스로 삼아,
**내정 + 외교 + 전쟁 + 무장 육성 + 사교(등용·의형제) + 동적 세계(재해·합종연횡)**를 담은 올라운드 게임으로 확장했습니다.

순수 **HTML + CSS + Vanilla JavaScript**로 구현되어 빌드 도구나 외부 의존성이 전혀 없습니다.
(npm / node_modules / 외부 CDN / 외부 폰트 없이 오프라인에서 완전히 동작합니다.)

---

## 실행 방법

브라우저의 보안 정책상 `file://` 로 직접 열면 일부 동작이 제한될 수 있으므로,
간단한 로컬 정적 서버로 서빙하는 것을 권장합니다. (Python 3만 있으면 됩니다.)

```bash
cd /projects/sandbox/Samguki
python3 -m http.server 8000
```

그 다음 브라우저에서 접속합니다:

```
http://localhost:8000
```

> 참고: 별도 서버 없이 `index.html` 파일을 브라우저로 직접 열어도 대부분 동작합니다
> (모든 스크립트가 일반 `<script>` 태그로 로드되며 ES Module을 쓰지 않기 때문입니다).
> 다만 안정적인 실행을 위해 위의 로컬 서버 방식을 권장합니다.

## 게임 흐름

1. **타이틀 화면** — "새 게임 시작"을 누릅니다. 저장된 게임이 있으면 **"이어하기"**로 불러올 수 있습니다.
2. **개막 국면(시나리오) 선택** — 한반도 삼국시대의 역사적 분기점 중 하나를 고릅니다. 각 국면은 시작 연도·정세·외교 관계·세력별 강약이 다릅니다.
3. **세력 선택** — 해당 국면에서 플레이 가능한 세력 중 하나를 고릅니다. 각 국가는 고유의 색상 테마, 난이도, 특성, 초기 병력을 가집니다.
3-1. **AI 난이도 선택 (보통 / 어려움 / 지옥)** — 플레이 방식 화면에서 고릅니다.
   - **보통**: AI와 대등한 승부 (숙련 플레이어 승률 ≈ 절반)
   - **어려움**: AI가 경제 보너스·병력 증원·선두 세력 공조로 압박 (승률 ≈ 20% 미만)
   - **지옥**: AI가 사정없이 몰아친다 (승률 한 자릿수)
   > AI는 매 턴 모든 성을 운영(개발·시설 증축·대군 모집)하고, 위험한 성에 병력을 증원하며, 선두(특히 플레이어)를 집중 견제합니다. 난이도는 수백 판의 시뮬레이션으로 승률 곡선을 맞췄습니다.
3-2. **플레이 방식 선택 — 군주제 / 장수제**
   - **군주제(君主制)**: 세력 전체를 직접 통치합니다. 내정·외교·군사를 모두 지휘하여 천하를 통일합니다.
   - **장수제(將帥制)**: 한 명의 무장이 되어 주군을 섬깁니다. 세력은 AI가 다스리고, 플레이어는 **근무·훈련·임무·출전·사사(師事)**로 **공훈(功勳)**과 **기능(技能)**을 쌓아 **승진**합니다 (백의종군→부장→교위→장군→태수→대장군→재상). 장군이 되면 성의 **태수**로 부임할 수 있고, 태수 이상이면 **실권을 장악해 직접 군주가 될 수도** 있습니다. 주군이 천하를 통일하면 함께 승리합니다.
4. **메인 게임 화면**
   - 한반도·만주·대륙(당)·열도(왜)를 아우른 지도에서 성(도시)을 클릭해 정보를 확인합니다.
   - 아군 성: **내정**(개발) / **출병**(공격) 가능
   - 적/중립 성: **공격** 가능
   - 상단 HUD: 금, 세수, 총병력, 영지 수, 연도/턴
   - 좌측 메뉴: 군주제는 **무장 / 등용 / 외교 / 연표**, 장수제는 **근무 / 무장 / 연표**
   - "턴 종료"를 누르면 세수 수입, 병력 회복, AI 행동, 역사 이벤트, **재해·합종연횡** 등이 처리됩니다.

## 주요 시스템

### 내정 — *노부나가의 야망 참고 (兵糧·民心·세율·시설)*
KOEI 사의 **노부나가의 야망**을 참고하여 내정을 전략의 중심으로 심화했습니다.
- **군량(兵糧)**: 금과 별개의 자원. 매 턴 농업·관개 레벨만큼 수확하고 병력이 소비합니다. **군량이 바닥나면 병사가 이탈**합니다 (HUD에 보유량·수지 표시).
- **민심(民心)**: 성마다 0~100. 세수·군량 수확·병사 모집 효율에 영향을 주고, 낮으면 재해 확률이 오릅니다. **구휼(선정)**로 끌어올립니다.
- **세율(세율)**: 경세/보통/중세 중 선택. 중세는 세수가 늘지만 민심이 깎이고, 경세는 반대입니다.
- **시설 레벨**: 관개(농업)/시장(상업)/성채(치안)를 1→3레벨까지 **증축**하면 능력치 상한과 세수·수확 배율이 오릅니다. (관개는 수해·가뭄 피해도 경감 — 치수 개념)
- **담당관(태수) 정치력**: 성에 배치된 무장의 정치력이 높을수록 **개발 효율**이 올라갑니다.
- 개발 명령: 농업 개발 / 상업 진흥 / 성벽 보강 / 민심 안정(구휼) / 병사 모집(금+군량)

### 외교 (5×5 관계)
사신 파견, 조공, 동맹 제안(관계 30 이상), 선전포고

### 군단 전투 — *영웅입지전·토탈워 삼국 참고*
턴제 전술 전투를 대폭 심화했습니다.
- **사기(士氣)와 궤주(潰走)**: 병력과 별개로 사기가 있으며, **사기가 무너지면 병력이 남아 있어도 적이 궤주**하여 승패가 갈립니다. (토탈워식 사기 전투)
- **병종(兵種) 상성**: 보병 → 기병 → 궁병 → 보병의 가위바위보 상성. 세력마다 주력 병종이 다릅니다 (고구려=기병, 왜=궁병, 신라=보병 등).
- **진형(陣形)**: 어린(魚鱗, 돌파)·학익(鶴翼, 포위/상성↑)·방원(方圓, 방어)을 매 턴 바꿔 전황에 대응합니다.
- **전법·계략**: 무장의 **지력**이 높을수록 성공률이 오르는 전법으로 적 사기·병력을 급감시킵니다 (쿨다운 있음).
- **일기토(一騎討)**: 전투 중 양 장수가 단기를 벌여 승부에 따라 사기를 크게 흔듭니다.
- **공성전/야전** 구분, **지원 무장** 참전(보너스), 지형(치안) 보정 — 피해는 무장 유효 능력치·진형·상성·사기를 종합해 계산합니다.

### 삼혼(三魂) 수련 — *Three Spirits 오마주*
무장마다 **통솔혼 / 무혼 / 지혼**을 갈고닦아 유효 능력치를 끌어올립니다.
- 통솔혼 → 통솔, 무혼 → 무력, 지혼 → 지력·정치에 보너스 (수련치의 절반, 상한 100)

### 기능(技能) — *태합입지전5 참고*
무장마다 **8가지 기능**을 Lv.0~4로 갖습니다 (초기 레벨은 능력치로 결정 — 예: 김유신은 무예·군학·변설 Lv.3, 선덕여왕은 변설·예법 Lv.3). 기능은 관련 행동으로 숙련도가 쌓여 레벨업하며, 장수제에서는 **사사(師事)**로 직접 수련할 수 있습니다.
| 기능 | 효과 |
|------|------|
| 무예(武藝) | 일기토·근접 전투 보정 |
| 궁술(弓術) | 궁병 전투 보정 |
| 기마(騎馬) | 기병 전투 보정 |
| 군학(軍學) | 전법 성공률·전투 사기 상승 |
| 의술(醫術) | 일기토 중 체력 회복 |
| 변설(辯舌) | 설전·외교 성공률 상승 |
| 산술(算術) | 내정 근무·임무의 금·공훈 효율 상승 |
| 예법(禮法) | 민심·개발 효율 상승 |

### 일기토(一騎討) & 설전(舌戰) — *3대 전투 모드 오마주*
- **일기토**: 무력·무혼을 겨루는 무장 단기(맹공/신중/허허실실). 승리 시 무혼·충성 상승, 패자 충성 하락.
- **설전**: 지력·정치·지혼을 겨루는 논쟁(정론/달변/반문). 승리 시 상대 충성이 크게 흔들려 **등용에 유리**해집니다.

### 등용 & 의형제 — *Oath of Brotherhood 오마주*
- **등용**: 재야(在野) 무장, 또는 충성이 흔들리는 타국 무장을 금과 설득으로 아군으로 맞이합니다. 성공률은 상대 충성에 반비례합니다.
- **의형제 결의(도원결의)**: 아군 무장 둘을 의형제로 맺어 서로의 충성·결속을 높입니다.

### 동적 세계 — *재해 & 합종연횡 오마주*
- **재해(6종)**: 지진 / 홍수 / 가뭄 / 황충 / 역병 / 폭설이 매 턴 확률로 특정 성을 강타합니다.
- **합종연횡(合從連衡)**: 한 세력이 압도적으로 강해지면 나머지 세력이 **합종**하여 견제합니다. 플레이어가 최강이면 사방이 적이 됩니다.
- **무장 이탈**: 충성이 바닥난 타국 무장은 불만을 품고 **재야로 이탈**합니다 (이후 등용 대상이 됩니다).

### 세이브 / 로드
브라우저의 `localStorage`에 게임을 저장합니다 (서버·파일 불필요, 설치 없음).
- **자동 저장**: 매 턴 종료 시 자동으로 갱신됩니다.
- **수동 저장 슬롯 3개**: 게임 중 좌측 **"저장"** 메뉴에서 원하는 슬롯에 저장/불러오기/삭제.
- **이어하기**: 타이틀 화면에서 저장된 게임(자동 저장 포함)을 불러옵니다.
- 각 저장은 세력·플레이 방식·난이도·연도·턴·저장 시각을 함께 보여줍니다.
- 사생활 보호 모드 등 저장이 불가능한 환경에서는 안내 메시지를 표시하고 게임은 정상 진행됩니다.

### 승리 / 패배 조건
- **승리**: 중립을 제외한 모든 성을 차지(천하통일) 하거나, 200턴 시점에 최다 성 보유
- **패배**: 보유한 성이 모두 함락되거나, 200턴 시점에 최다 성 보유국이 아님

### 이벤트 (30종) — *역사 이벤트 + 선택지 이벤트*
**역사 이벤트(19종)**: 살수대첩·황산벌·기벌포·관산성·나당연합·평양 천도·백제 전성기·화랑도 창설·불교 공인·대기근, 그리고 삼국유사·삼국사기 기반의 이차돈의 순교·만파식적·서동요·원효의 화쟁·불국사·온달·관창·백강 전투·안시성 싸움 등이 턴 진행 중 발생합니다.

**선택지 이벤트(選擇肢, 신규)**: 플레이어의 결정이 국면을 바꿉니다. 트레이드오프가 있는 선택지를 골라 민심·재정·병력·외교를 조정합니다.
- 공통 돌발 이벤트: 흉년(구휼 vs 비축), 떠도는 호걸(등용), 국경의 도적떼(토벌/방관/회유), 서역 대상의 교역, 하늘의 조짐, 대풍년, 노련한 책사의 조언 등 — **반복 발생**하며 매번 선택을 요구합니다.
- **장수제 전용**: 주군의 부름(선봉/내정), 의형제의 제안 — 공훈·기능·충성에 영향.
- **군주제 전용**: 탐관오리 처결, 적국의 밀사(투항 회유) — 민심·재정·병력에 영향.
- 이벤트는 플레이 방식(군주/장수)·조건·세력에 따라 선별되어 등장합니다.

## 기술 메모
- 프레임워크·번들러 없이 동작하는 순수 웹 기술 구현입니다.
- 전역 네임스페이스 `window.SAMGUK` 아래에 데이터/스토어/UI 모듈을 등록합니다.
- 상태는 단일 상태 객체 + 구독(subscribe)/전체 재렌더 방식으로 관리합니다.
- 지도, 국가 엠블럼, 전장 그리드는 모두 인라인 SVG로 그립니다. 지도는 고지도풍으로 지형 그라디언트·하천·산맥 능선·나침반·그림자 필터를 적용했고, 도시 마커는 성채 레벨·민심·인구를 시각화합니다.
- 폰트는 시스템에 설치된 한글 폰트 스택을 사용합니다 (외부 폰트 로딩 없음).
